Venura 6.5 thinks deeper, stays with a task longer and checks its work before handing it over. The successor to Venura 6 — built for Code, Science and everything that takes more than one attempt.

Today Venura 6 is the tier you reach for when a task gets hard: architecture, debugging, long derivations. Venura 6.5 starts exactly where it reaches its limits — tasks that stretch across many steps, many files and many tool calls.

The goal is not a faster answer, but one you never have to ask for twice.

What changes

  1. 01

    Stays on task longer

    Long sessions in Code and Cowork are meant to keep their thread, even when the history reaches the context limit and gets summarised.

  2. 02

    Cleaner tool chains

    Fewer unnecessary calls, better choices between search, Python and file access — and a plan that stays visible while it is worked through.

  3. 03

    Its own review pass

    Before an answer goes out, the model reads it back against the task and the tool results. Anything it cannot back up is marked as open instead of asserted.

  4. 04

    Images and figures

    More accurate reading of charts, screenshots and formulas — essential for Science, where a figure is the answer.

Where it runs

Everywhere you pick a model tier today — no separate access and no new keys.

  • Chat Everyday questions, long threads
  • Code Real projects, real terminal
  • Science Databases and a Python chamber
  • Cowork Finished files, ready to sign off
  • Public API Same tier, same key

Availability and pricing

Venura 6.5 replaces Venura 6 in the same place in the model picker. If you have Venura 6 selected, there is nothing to change — neither in the interface nor in the API.

We will publish prices per million tokens at launch, in the console and on the pricing page. Until then everything runs on Venura 6 as usual.

Questions

Do I have to change anything?

No. Venura 6.5 takes Venura 6’s place. Settings, keys and workspaces stay exactly as they are.

What happens to Venura 6?

It stays selectable for a transition period after launch, so running projects can switch without hurry. We will announce the exact period at launch.

Can I try it before launch?

Not publicly. Until the end of November every tool runs on Venura 6 — whatever you build there keeps working afterwards without changes.
